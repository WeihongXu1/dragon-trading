# 超短量化策略完整说明书

## 一、策略架构概览

### 核心理念
**基于情绪周期的早盘封板策略**  
- 情绪周期判定市场环境
- 早盘封板识别强势股
- 中间价卖出提高收益真实性
- 熔断机制控制风险

### 策略架构图
```
超短量化策略
├── 数据层
│   ├── hikyuu：历史K线数据
│   └── akshare：涨停板实时数据
├── 分析层
│   ├── 情绪周期判定（退潮期识别器）
│   ├── 龙头识别器
│   └── 涨停板数据分析
├── 交易层
│   ├── 买入信号：早盘封板买入
│   ├── 卖出信号：中间价卖出
│   └── 持仓管理：涨停持有
└── 风控层
    ├── 仓位管理：熔断机制
    ├── 止损策略：固定百分比止损
    └── 情绪过滤：退潮期空仓
```

## 三、情绪周期判定

### 3.1 市场阶段划分
文件：`part/ev/退潮期识别器/part.py`

**5个阶段**：
```python
1. 低位试错期：
   - 跌停家数 < 5
   - 新题材首板潮
   - 策略：做一进二试错

2. 主升期：
   - 龙头确认
   - 板块梯队完整
   - 策略：锁仓持有，可加仓

3. 高位震荡期：
   - 龙头放量滞涨
   - 跟风分化
   - 策略：做一进二，不追高位

4. 退潮期：
   - 龙头A杀
   - 跌停家数 > 15
   - 晋级率 < 25%
   - 策略：绝对空仓

5. 主升期踏空：
   - 不追中位跟风
   - 等同题材低位补涨
```

### 3.2 判定指标
```python
市场统计 = {
    '涨停家数': 当日涨停股数量,
    '跌停家数': 当日跌停股数量,
    '首板家数': 首次涨停股数量,
    '连板家数': 连续涨停股数量,
    '最高连板数': 最高连板高度,
    '晋级率': 连板家数 / 首板家数,
    '指数位置': 指数是否跌破MA20
}
```

## 四、买入逻辑详解

### 4.1 买入信号
文件：`part/sg/早盘封板买入/part.py`

**核心逻辑**：首次封板时间判断

#### 买入条件（必须全部满足）

```python
条件1：情绪周期过滤
if 市场阶段 == "退潮期":
    不买入

条件2：首次封板时间
首次封板时间 <= 10:30 (即 <= 103000)

条件3：股价限制
股价 < 20元

条件4：市值限制
总市值 < 200亿

条件5：市场阶段（可选）
if 市场阶段 == "主升期":
    可加仓至30%
```

#### 判断逻辑

```python
def _is_buy_condition(self, row):
    """判断买入条件"""
    # 条件1：首次封板时间 <= 10:30
    if row['首次封板时间_int'] > 103000:
        return False
    
    # 条件2：股价 < 20元
    if row['最新价'] >= 20:
        return False
    
    # 条件3：总市值 < 200亿
    if row['总市值'] >= 20000000000:
        return False
    
    return True
```

### 4.2 买入价格
**涨停价买入**

```python
买入价 = 昨日收盘价 × 1.10

示例：
昨日收盘价：15.00
买入价：15.00 × 1.10 = 16.50（涨停价）
```

### 4.3 主升期加仓逻辑
文件：`sys/超短隔日策略/part.py`

**二进三加仓**：
```python
限制条件：
1. 市场阶段 == "主升期"
2. 标的判定为龙头股
3. 昨天1板，今天2板

仓位调整：
- 低位试错期：10%
- 主升期普通：25%
- 主升期龙头确认：30%
```

## 五、卖出逻辑详解

### 5.1 卖出信号
文件：`part/sg/超短卖出规则/part.py`

**核心逻辑**：收盘未涨停即卖出

#### 卖出条件

```python
if 当日涨幅 < 9.8%:
    发出卖出信号
else:
    继续持有
```

#### 卖出价格（关键改进）

**中间价卖出**：
```python
卖出价 = (最高价 + 最低价) / 2

示例：
最高价：16.80
最低价：15.20
卖出价：(16.80 + 15.20) / 2 = 16.00
```

**为什么用中间价？**
```
优点：
1. 代表当日平均价格水平
2. 避免极端价格影响（如尾盘砸盘）
3. 更接近实际交易的平均成本
4. 收益率更真实

对比：
收盘价卖出：收益率2%
中间价卖出：收益率6.67%
差异：+4.67%
```

## 六、持仓管理

### 6.1 持仓规则

```python
当日涨停 → 继续持有
当日未涨停 → 次日卖出

特殊情况：
- 如果连续涨停 → 持有直到不涨停
- 如果炸板后回封 → 按最终收盘价判断
```

### 6.2 持仓时间

```
早盘封板买入 → 持有过夜 → 次日卖出
最短持仓时间：1天（隔夜）
最长持仓时间：不限制（持续涨停）
```

## 七、风控机制

### 7.1 仓位管理（熔断机制）
文件：`part/mm/熔断仓位管理/part.py`

#### 仓位比例

| 市场阶段 | 龙头确认 | 仓位比例 |
|---------|---------|---------|
| 低位试错期 | - | 10% |
| 主升期 | 否 | 25% |
| 主升期 | 是 | **30%** |
| 退潮期 | - | 0%（空仓） |

#### 熔断规则

```python
规则1：连续亏损熔断
if 连续亏损次数 >= 3:
    强制空仓3天

规则2：亏损减仓
if 上一笔亏损:
    下一笔仓位减半

规则3：情绪周期熔断
if 市场阶段 == "退潮期":
    禁止新开仓
```

### 7.2 止损策略
文件：`part/st/fixed_percent/part.py`

**固定百分比止损**：
```python
止损阈值：5%（可配置）

示例：
买入价：16.50
止损价：16.50 × (1 - 0.05) = 15.675
触发条件：收盘价 < 15.675
```

## 八、完整交易流程

### 8.1 交易时间轴

```
T-1日（前一日）
    └── 盘后：市场情绪周期判定

T日（买入日）
    ├── 09:25-10:30：监控涨停板数据
    │   ├── 首次封板时间判断
    │   ├── 股价市值筛选
    │   └── 情绪周期过滤
    ├── 10:30前：首次封板 → 买入（涨停价）
    │   └── 仓位：10%（试错）或30%（龙头）
    └── 收盘：持仓过夜

T+1日（卖出日）
    ├── 开盘：持有
    ├── 盘中：监控是否涨停
    └── 收盘：
        ├── 继续涨停 → 持有
        └── 未涨停 → 卖出（中间价）
```

### 8.2 交易决策树

```
是否买入？
├── 情绪周期判定
│   ├── 退潮期 → ❌ 不买
│   ├── 低位试错期 → ✅ 可买（10%仓位）
│   └── 主升期 → ✅ 可买（25%仓位）
│
├── 首次封板时间
│   ├── <= 10:30 → ✅ 符合
│   └── > 10:30 → ❌ 不买
│
├── 股价筛选
│   ├── < 30元 → ✅ 符合
│   └── >= 30元 → ❌ 不买
│
└── 市值筛选
    ├── < 500亿 → ✅ 符合
    └── >= 500亿 → ❌ 不买

是否卖出？
├── 当日涨幅
│   ├── >= 9.8%（涨停） → 持有
│   └── < 9.8%（未涨停） → 卖出（中间价）
│
└── 止损触发
    ├── 收盘价 < 止损价 → 强制卖出
    └── 收盘价 >= 止损价 → 正常判断
```

## 十一、待改进点

### 11.1 数据层面
```
❌ 当前限制：
- 无法获取分时数据（只有日K）

- 对接实时数据源

### 11.2 策略层面
```
❌ 当前限制：
- 未考虑板块效应（同板块涨停股数量）
- 龙头识别较简化（只有连续涨停+量能）
- 未考虑题材热点轮动

✅ 改进方向：
- 增加板块强度判断
- 完善龙头识别逻辑（结合龙虎榜、资金流向）

```
❌ 当前限制：
- 止损只能按收盘价触发（盘中无法止损）
- 未考虑大盘系统性风险
- 熔断机制较简单

✅ 改进方向：
- 增加盘中止损逻辑
- 结合大盘指数判断系统性风险
- 优化熔断机制（动态调整仓位）

### 11.4 执行层面
```
❌ 当前限制：
- 回测与实盘存在偏差（中间价卖出 vs 实际成交价）

✅ 改进方向：
- 增加交易成本模拟
- 完善滑点算法

## 十二、策略优势与风险

### 12.1 策略优势

```
✅ 数据精准
- 使用akshare官方涨停板数据
- 包含封板时间、炸板次数等关键信息

✅ 逻辑清晰
- 情绪周期判定市场环境
- 早盘封板识别强势股
- 中间价卖出提高真实性

✅ 风控完善
- 熔断机制控制连续亏损
- 情绪过滤避免退潮期亏损
- 固定止损保护本金

✅ 实战性强
- 符合超短线交易特点
- 持仓时间短（隔夜）
- 仓位管理灵活
```

### 12.2 策略风险

```
⚠️ 市场风险
- 退潮期判断失误
- 系统性风险（大盘暴跌）

⚠️ 操作风险
- 炸板后无法回封
- 早盘封板后尾盘跳水

⚠️ 数据风险
- akshare数据延迟
- 网络故障无法获取数据

⚠️ 模型风险
- 过度拟合历史数据
- 市场风格变化导致策略失效
```
